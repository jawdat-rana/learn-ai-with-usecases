# The 10 challenges

Tick these off on your website's home page (it remembers your ticks in your
browser), or edit this file and change `[ ]` to `[x]`.

- [ ] **1. Live.** Your own copy and website are live (see [START-HERE](START-HERE.md)).
- [ ] **2. Better brief.** Write an R-C-T-F-C prompt for a real, non-confidential work task and run it in two different AI tools. Note the differences in your journal.
- [ ] **3. Risk radar.** Finish Module 1 and find the 4 high-risk suppliers.
- [ ] **4. Caught it.** Catch an AI making a mistake (the Northwind trap counts) and get it to explain why it went wrong.
- [ ] **5. Code without coding.** Run AI-written Python in Google Colab or in your AI chat, without typing any code yourself.
- [ ] **6. Change it in English.** Ask the AI to change the code (a new threshold, a 4-week closure) and re-run it.
- [ ] **7. War room.** Finish Module 2 and write a decision memo you'd be happy to send.
- [ ] **8. Real work.** Use one prompt kit on a real document from your job (anonymised, and only in a tool your company allows).
- [ ] **9. Ship a page.** Publish a new web page the AI built for you on your GitHub Pages site.
- [ ] **10. Advanced.** Build and test your own skill, or run an agent team ([Part 2](part-2-advanced/README.md)).

**Finished all ten?** Share your website link with the group and tell
everyone the most useful prompt you found.

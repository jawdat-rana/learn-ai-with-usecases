# Prompt kits: reusable tools for everyday senior work

Each kit is a ready-made prompt you can reuse every week. Each one comes with
a synthetic sample so you can try it safely, a description of what a good
answer looks like, and a **"where AI is wrong"** section.

| Kit | Use it when | Time saved (typical) | Code? |
|---|---|---|---|
| [Steering committee transcript → decisions, owners, risks](steerco-transcript-to-decisions.md) | After any meeting with a transcript or messy notes | 30-60 min per meeting | No |
| [Contract and SLA risk review](contract-sla-review.md) | Before signing or renewing a supplier, 3PL or service contract | First-pass review in minutes | No |
| [Demand forecast sanity check](demand-forecast-sanity-check.md) | Before an S&OP meeting or when a forecast "feels off" | 1-2 hours | Python, AI-written |
| [Project plan stress test](project-plan-stress-test.md) | Before a go/no-go, or when a plan has too many moving parts | 1-2 hours | Python, AI-written |

**How to save a kit so you reuse it:** keep the prompt in your
[journal](../my-ai-journal.md), or turn it into a reusable skill or custom
assistant in [Part 2](../part-2-advanced/README.md).
